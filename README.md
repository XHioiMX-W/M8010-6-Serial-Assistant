# M8010-6 串口助手

双击 [Start-M8010SerialAssistant.cmd](Start-M8010SerialAssistant.cmd) 启动程序。

新增独立“电机 ID”页：读取 ID、选择控制目标、单电机修改 ID、自动恢复电机模式并校验新 ID。修改时总线只能连接一台电机。

新增“多电机程序”页：预置 ID 2–9 以输出轴 1 rad/s 各运行 2 秒的顺序程序，也支持最多 8 台同时运行。每台可设置 ID、正反向速度、时长，支持参数保存 / 载入、实时状态及整组停止。

完整的安装、操作和 GO-M8010-6 v1.2 协议说明请参阅 [README-M8010.md](README-M8010.md)。

顶部展示设计横幅，图片放在 `assets` 目录，请与程序一起保留。
