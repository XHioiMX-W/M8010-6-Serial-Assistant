# M8010-6 串口助手

这是一个面向 Windows 的宇树 M8010-6 电机串口控制工具。程序使用 PowerShell/WPF 编写，不需要安装 Python、Node 或 .NET SDK；Windows 10/11 自带的 Windows PowerShell 5.1 即可运行。

双击 `Start-M8010SerialAssistant.cmd` 启动。连接 USB-RS485 适配器后点击“刷新端口”，默认通信参数是 `4000000 baud / 8-N-1`。M8010 协议是二进制数据，界面中的控制帧和反馈帧均以十六进制显示。

一条 RS-485 总线最多挂载 15 台电机（ID 0–14），不能有重复 ID；ID 15 是广播地址，不返回反馈。界面默认目标 ID 为 0，实际控制前必须确认它和电机 ID 一致，否则电机会忽略控制帧。

主要功能：

- STATUS 0 锁定、STATUS 1 FOC 闭环、STATUS 2 编码器校准。
- FOC 下的 6 种策略：当前位置保持、速度控制、阻尼、恒力矩、零力矩、力位混合。
- 正转、反转、停止/锁定、急停、速度微调和周期发送。
- 目标转矩、速度、位置、Kpos、Kspd 输入，范围检查和小端打包。
- 在界面线程轮询解析 16 字节反馈帧，显示实际转矩、速度、位置、温度、错误码和 FORCE。
- 原始十六进制发送、通信日志、CRC 错误统计和帧头同步。

七种 FOC 策略对应手册第 7 节。策略按钮只装载参数，不直接启动输出。当前位置保持允许先选策略；启动时会发送 STATUS 0 读取目标电机当前位置，收到匹配 ID 的反馈后立即把该位置作为目标并启动，避免依赖用户在短时间内完成点击。读不到匹配反馈时不会启动，可修正 ID/连接后重试。位置保持按手册第 7.2 节使用 `T=0, W=0, Kpos=0.02, Kspd=0`；运行中手动调整位置目标仍以 `0.5 rad/s` 输出轴速度斜坡移动，避免位置突变产生过大电流。速度控制分为“缓速启动”和“直接到达”：前者使用 `T=0, Kp=0, Kw=0.02`，默认输出轴目标速度为 `0.5 rad/s`，启动时从反馈速度缓慢变化，斜率为 `1 rad/s²`；后者启动首帧即发送设定速度，运行中的目标修改也不经过速度斜坡。目标速度只受协议转子侧 `±804 rad/s` 可编码范围约束，启用输出轴单位时会按减速比换算。阻尼模式是 `W=0, Kp=0, Kw=0.02`。恒力矩不再自动填入非零值；启动前要求明确输入并确认，因为空载时电机可能持续加速；启动和运行期间转矩目标按 `0.1 N·m/s` 输出轴等效斜率缓升，混合模式的转矩分量也使用相同斜率。反馈速度按手册定义为输出轴速度；“连接与安全”页的自动锁定阈值必须由用户填写，程序不会预设。阈值范围为大于 `0` 且不高于反馈协议量程 `804 rad/s`，运行期间固定。数据手册标注的 `30 rad/s（24 V）` 是电机规格参考，不会自动用作保护值；应结合实际供电、负载和机构限速自行设定。超过所填阈值时程序停止周期输出并发送 STATUS 0 锁定。零力矩模式（所有目标为 `0`）仍处于 FOC 主动控制状态。力位混合会保留当前参数，启动前应逐项检查。正转/反转按钮只改变速度目标；运行中目标通过所选速度策略更新，未运行时需检查后手动启动。

正常操作不需要填写或计算十六进制帧；原始帧入口已收纳在“高级诊断”折叠区，只建议在抓包或故障定位时使用。

## 协议摘要

控制帧固定 17 字节：`FE EE` + 1 字节模式 + 12 字节参数 + 2 字节 CRC。模式字节为：

```text
byte2 = (STATUS << 4) | ID
ID     = 0..14，15 为广播（广播不返回反馈）
STATUS = 0 锁定，1 FOC，2 编码器校准，3..7 保留
```

参数按小端整数发送：`tau_set = torque(N·m) * 256`，`omega_set = speed(rad/s) / (2π) * 256`，`theta_set = position(rad) / (2π) * 32768`，`Kpos/Kspd = gain * 1280`。CRC 是 CRC16-CCITT 的反射实现（多项式 `0x8408`、初值 `0`、异或输出 `0`），覆盖 CRC 之前的所有字节，低字节先发送。

反馈帧固定 16 字节，帧头为 `FD EE`。反馈 FORCE 是 12 位原始值，物理单位需要以电机当前版本手册为准；温度达到 90 °C 或出现错误码时应停止输出并检查机械、电气和线缆。

手册中的控制目标默认都是电机转子侧，GO-M8010-6 的减速比是 `6.33`。界面默认勾选“目标按输出轴单位输入”，位置和速度会按减速比换算，转矩按理想减速比估算；取消勾选即可直接输入转子侧参数。反馈位置/速度按手册表 2 的实际关节输出值显示，锁存位置时会根据勾选单位转换到目标输入坐标。

编码器校准是一个特殊流程：STATUS 2 发出后必须等待约 5 秒，期间不能发送任何数据包。程序会自动锁定控制、周期发送和高级原始帧入口，并显示倒计时。手册要求供电不高于 DC 30 V；温度保护触发后需要重新给电机上电才能恢复控制。

## 自测

在 PowerShell 中运行：

```powershell
.\Test-M8010Protocol.ps1
```

测试会校验 README 中的运行/停止样例帧、反馈字段、连续帧同步和 CRC 错误处理。实际接电机前请先确认 USB-RS485 模块、终端电阻、供电和 4 Mbps 信号完整性。

程序不会在串口驱动线程中执行 PowerShell 回调；反馈由界面线程每 10 ms 读取，避免 Windows PowerShell 的跨线程脚本块崩溃。若发生可恢复的界面异常，完整信息会写入 `M8010SerialAssistant-errors.log`。

停止按钮、急停按钮和手动取消“连续发送”都会停止周期发送并发送 STATUS 0 锁定帧。位置/速度斜坡限制目标变化速度，不代表机械负载、夹点或电流风险可以忽略；首次调试应空载、固定电机并保持急停可用。

## FOC 不转时的检查顺序

1. 在“连接与安全”页确认目标 ID。程序默认使用 ID `0`，必须与电机实际 ID 一致；ID 不匹配时电机会忽略控制帧。
2. 在“FOC 控制”页选择“速度控制”，确认目标速度不是 0，然后点击“启动 FOC”。程序会先发送一帧，再按周期（默认 20 ms）持续发送。
3. 在“诊断”页确认最后发送帧以 `FE EE 10` 开头；默认输出轴速度目标是 `0.5 rad/s`，启动后会按 `1 rad/s²` 缓升，控制目标再按 `6.33` 换算为转子侧。
4. 在“状态监视”页确认反馈状态为“FOC 闭环”、错误码为 0，温度低于 90 °C。出现错误码或过热时程序会自动停止周期发送。
5. 检查 RS-485 收发方向、共地、终端电阻和 4 Mbps 信号质量。广播 ID `15` 不返回反馈，只适合同时下发，不适合确认单台电机状态。
